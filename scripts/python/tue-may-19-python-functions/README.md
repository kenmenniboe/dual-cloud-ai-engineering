## 💡 Key Takeaways

- A function is a **reusable block of code** — define once, call many times.
- `print` shows a value and **forgets it**. `return` **hands it back** to be used later.
- `*args` bundles unlimited arguments into a **tuple**. `**kwargs` bundles them into a **dictionary**.
- **Local** variables live inside functions only. **Global** variables are accessible anywhere.
- A **lambda** is a one-line function — no `def`, no `return`, just `lambda params: expression`.
- A **higher-order function** accepts another function as an argument.
