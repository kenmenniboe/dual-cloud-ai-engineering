## 💡 Key Takeaways

- A **loop** lets you repeat a task without writing the same code over and over (**DRY** — Don't Repeat Yourself)
- A `for` loop repeats a **set number of times**
- A `while` loop repeats **as long as something is true**
- `range()` generates a sequence of numbers to loop through
- `break` stops a loop completely; `continue` skips one item and keeps going
- **Nested loops** are loops inside loops
- `enumerate()` gives you both the **position** and the **item** while looping
- Code **inside** a loop runs multiple times; code **outside** runs only once
