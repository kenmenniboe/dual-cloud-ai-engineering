# Git & GitHub Mini Tutorial
**Date:** Thu Jun 26  
**Goal:** Enterprise Git & GitHub mastery for cloud-native DevOps — interview-ready, production-safe

---

## Learning Objectives

By the end of this tutorial you will be able to:

- Explain Git's three-area model and commit/push/pull workflow
- Manage local and remote branches confidently
- Use rebasing, stashing, reflogs, and undoing changes safely
- Understand the difference between Git (tool) and GitHub (platform)
- Integrate Git with CI/CD pipelines using GitHub Actions
- Apply production-safe practices for force-pushing and history rewriting
